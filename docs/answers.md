# Ответы 

## 1. Чем отличается Git от GitHub?

Git — распределённая система контроля версий, работающая локально на компьютере. GitHub — облачная платформа для хранения Git-репозиториев и совместной работы. Git — инструмент, GitHub — сервис.

## 2. Для чего используется виртуальное окружение Python?

Виртуальное окружение (venv) изолирует зависимости проекта от системного Python. Это позволяет разным проектам использовать разные версии библиотек без конфликтов.

## 3. Что такое commit, branch, remote, pull request?

- Commit — фиксация изменений в истории проекта.
- Branch — отдельная ветка разработки, позволяющая вести работу параллельно.
- Remote — удалённый репозиторий (например, на GitHub).
- Pull Request — запрос на слияние изменений из одной ветки в другую.

## 4. Зачем нужен файл .gitignore?

Он указывает, какие файлы и папки не должны попадать в репозиторий (виртуальное окружение, кеш, секреты, временные файлы).

## 5. Как организовать командную работу над бизнес-приложением с помощью Git?

Каждый разработчик создаёт свою ветку под задачу, делает коммиты, отправляет ветку на GitHub и создаёт Pull Request. Другой участник проверяет изменения, оставляет комментарии и выполняет слияние в main.

## 6. Какие файлы обязательно должны быть в репозитории учебного проекта?

- README.md — описание проекта
- .gitignore — исключения
- requirements.txt — зависимости
- Исходный код (main.py, src/)
- Документация (docs/)

## 7. Что произойдёт, если два разработчика изменят один и тот же файл в разных ветках?

При попытке слияния возникнет конфликт. Git не сможет автоматически объединить изменения, и разработчику нужно будет вручную разрешить конфликт, выбрав нужные строки, а затем сделать коммит.
