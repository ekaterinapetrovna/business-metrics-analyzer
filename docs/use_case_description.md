# Описание ключевых Use Case

## UC-02. Формирование отчёта

| Поле | Значение |
|---|---|
| **Название** | Формирование отчёта |
| **Актор** | Аналитик |
| **Предусловие** | Пользователь авторизован, данные загружены |
| **Основной поток** | 1. Пользователь выбирает тип отчёта.<br>2. Указывает период.<br>3. Нажимает «Сформировать».<br>4. Система формирует отчёт.<br>5. Пользователь просматривает отчёт. |
| **Альтернативный поток** | Если данных за период нет — система выводит сообщение «Данные за период отсутствуют» |
| **Постусловие** | Отчёт сформирован и доступен для экспорта |

## UC-03. Загрузка данных о продажах

| Поле | Значение |
|---|---|
| **Название** | Загрузка данных о продажах |
| **Актор** | Менеджер по продажам |
| **Предусловие** | Пользователь авторизован с ролью «Менеджер» |
| **Основной поток** | 1. Пользователь открывает раздел «Загрузка данных».<br>2. Выбирает файл с данными.<br>3. Нажимает «Загрузить».<br>4. Система валидирует файл.<br>5. Система сохраняет данные и обновляет KPI. |
| **Альтернативный поток** | Если файл содержит ошибки — система выводит список ошибок и не сохраняет данные |
| **Постусловие** | Данные загружены, KPI пересчитаны |
